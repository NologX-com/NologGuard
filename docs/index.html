Tại sao phải dùng NologGuard?

Vượt rào cản ISP & bảo mật DNS mà không phải hy sinh tốc độ hay IP thật

So sánh nhanh giữa lướt web mặc định, VPN truyền thống, các tool dòng lệnh phức tạp và NologGuard.

ISP

Mặc định (Không bảo vệ)

Nhà mạng đọc hết tên miền qua DNS UDP 53, TLS SNI và QUIC. Dễ bị chặn web, theo dõi lịch sử truy cập và ngập tracker quảng cáo.

VPN

VPN truyền thống

Làm chậm băng thông, tăng ping khi chơi game/họp online, đổi IP nước ngoài khiến app ngân hàng, ví điện tử và CAPTCHA báo lỗi liên tục.

CMD

Tool rời / Script thủ công

Phải sửa Registry DoH, chạy file `.cmd` quyền Admin, cài driver kernel dễ đụng Anti-cheat game hoặc mất mạng nếu quên tắt.

✓

NologGuard (NoLogX.com)

1 nút bấm gọn sạch: không driver kernel, không cần Admin hằng ngày, giữ 100% IP thật & tốc độ, tự khôi phục mạng an toàn.

Bảo vệ trước nhà mạng (ISP)

Cách NologGuard giấu tên miền web truy cập khỏi hệ thống lọc ISP

Ngay cả khi dùng HTTPS, gói tin kết nối đầu tiên vẫn lộ tên miền ở 3 nơi (DNS, TLS SNI và QUIC). NologGuard xử lý đồng thời cả 3 tầng.

01 / BROWSER

Trình duyệt / App

Gửi HTTP CONNECT vào 127.0.0.1:8899 — trình duyệt tự bỏ QUIC UDP 443.

02 / ADBLOCK

Lọc tên miền QC

Trùng danh sách chặn sẽ trả 403 ngay lập tức trước khi hỏi DNS hay mở TCP.

03 / DOH HTTP/2

Giấu DNS khỏi ISP

Hỏi IP qua HTTPS HTTP/2 thẳng tới 9.9.9.9 / 1.1.1.1 — 0% rò rỉ cổng UDP 53.

04 / SNI SPLIT

Cắt SNI qua DPI

Đọc trọn ClientHello (cả TLS 1.3 hậu lượng tử) và cắt đôi tên miền SNI qua nhiều gói TCP.

Bắt đầu trong 30 giây — Không cần cấu hình phức tạp

1

Tải & Mở NologGuard

Cài bằng NologGuard-Setup.exe (cài im lặng bằng /VERYSILENT) hoặc chạy thẳng 1 file NologGuard.exe dưới quyền USER bình thường.

2

Bật khiên & Tự kiểm tra

Bấm BẬT BẢO VỆ ở tab Bảo vệ. Bấm Tự kiểm tra ngay cạnh mục DoH để xác nhận DoH và AdBlock 403 Loopback OK.

3

Tăng cường chặn quảng cáo Việt Nam

Vào tab Chặn QC -> chọn hostsVN (hoặc dán Link bộ lọc tùy chỉnh) -> bấm Tải / Cập nhật. Dùng @@domain.com để mở ngoại lệ nhanh.

4

Tùy chọn Admin & Khôi phục sự cố

Chỉ cần bấm Chạy quyền Admin nếu muốn bật DoH toàn Windows 11 hoặc Firewall chặn UDP 443. Nếu cúp điện kẹt Proxy, chạy NologGuard.exe --recover.
